# fisafisa.net

My personal static website, [fisafisa.net](https://fisafisa.net),
served by GitHub Pages.

The site is generated by [Pollen](https://docs.racket-lang.org/pollen/), a
publishing system built on Racket. Its source (the pages, the data they share,
and the templates) lives in a private repository, and Pollen renders it into
the plain HTML, CSS and PDFs here. Only this processed output is public.

- `*.html`, `style.css`: the pages
- `content/files/`: papers, slides, and the CV, typeset with
  [Typst](https://typst.app) from the same data as the site
- `fonts/`: Courier Prime and a one-glyph cut of Adwaita Mono, both under the
  SIL Open Font License
